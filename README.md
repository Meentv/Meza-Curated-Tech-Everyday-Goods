# Meza — Curated Tech & Everyday Goods

A responsive storefront concept for headphones, wearables, footwear, and everyday tech.

## Included

- `index.html` — full storefront homepage
- `style.css` — original visual system plus responsive polish and effects
- `script.js` — search, category filters, mobile navigation, local cart feedback, newsletter feedback, and hero parallax
- `assets/images/` — supplied product images

## Added interactions

- Responsive mobile navigation menu
- Search panel with live product filtering
- Category filter pills
- Quick-add buttons with a local cart counter
- Newsletter feedback message
- Gentle hero image parallax
- Subtle responsive hover and reveal-style motion
- Accessible labels and reduced-motion support

## Run locally

```bash
python3 -m http.server 4173
```

Then visit the project folder from `http://localhost:4173`.

## Note

The cart, search, and newsletter interactions are frontend-only demonstrations. Connect them to a real catalogue, checkout, and email/backend service before production.
